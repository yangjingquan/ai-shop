# Shared layout

## `admin/src/layouts/BasicLayout.vue`

The shared app shell uses a 236px dark-brown sticky sidebar, a light top header with a user dropdown, and a warm off-white scrollable content area. The menu stores label, description, icon character, path, and required permission in each menu item. Content is rendered through `<router-view />`.
