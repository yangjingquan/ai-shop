# Shared UI components

## `admin/src/components/upload/ImageUploader.vue`

Reusable Element Plus-based image uploader used by the merchant profile form. It accepts `v-model` and keeps the app's rounded-card upload treatment.

Other common primitives come from Element Plus (`el-card`, `el-form`, `el-button`, `el-tag`, `el-table`); their visual treatment is centralized in `admin/src/style.css`.
